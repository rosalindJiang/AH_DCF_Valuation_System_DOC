# 07 风险控制与结果校验

## 1. 为什么需要结果校验

DCF 模型对假设参数高度敏感。批量计算全市场股票时，若数据缺失、财务指标异常或参数设置不合理，容易产生明显错误的内在价值。因此系统必须设置数据质量和模型结果校验机制。

## 2. 数据质量检查

### 2.1 完整性检查

检查以下字段是否缺失：

- 收盘价；
- 总股本；
- 营业收入；
- EBIT；
- 资本开支；
- 现金；
- 有息负债；
- WACC；
- 终端增长率。

### 2.2 一致性检查

检查：

- 股票代码是否存在于基础信息表；
- 行情币种是否与估值币种一致；
- 财报日期是否早于估值日期；
- 同一股票同一报告期是否存在重复数据；
- 股本、市值和收盘价是否大致匹配。

### 2.3 异常值检查

| 指标 | 异常规则示例 |
|---|---|
| 收入增长率 | 大于 100% 或小于 -80% 触发提醒 |
| EBIT Margin | 大于 80% 或小于 -80% 触发提醒 |
| WACC | 小于 3% 或大于 25% 触发提醒 |
| 终端增长率 | 小于 0% 或大于 5% 触发提醒 |
| 终端价值占比 | 大于 90% 触发提醒 |
| 估值偏离度 | 大于 300% 或小于 -90% 触发提醒 |

## 3. 模型逻辑检查

系统必须检查：

```text
WACC > Terminal Growth Rate
Shares Outstanding > 0
Market Price > 0
Forecast Years >= 1
```

如果上述条件不满足，该股票不应输出正常估值结果，而应进入异常清单。

## 4. 结果分级

| 标记 | 含义 |
|---|---|
| PASS | 数据完整，结果正常 |
| WARNING | 可计算，但存在异常或需人工复核 |
| FAIL | 数据不足或模型假设无效，不能估值 |

## 5. 人工复核清单

以下情况建议人工复核：

- 内在价值明显远高于当前股价；
- 终端价值占比过高；
- 公司最近几年自由现金流持续为负；
- 财务报表出现大额一次性收益或亏损；
- 股票处于停牌、退市风险或重大重组状态；
- 金融类公司被普通 FCFF 模型估值。

## 6. 版本控制

每次估值结果应记录：

- `model_version`；
- `parameter_version`；
- `data_source_version`；
- `config_version`；
- `valuation_date`。

这样可以保证同一股票在不同日期、不同参数假设下的估值结果可追溯、可解释。
