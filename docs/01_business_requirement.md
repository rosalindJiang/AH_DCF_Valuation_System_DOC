# 01 业务需求说明

## 1. 项目题目

设计一个全市场 AH 股 DCF 估值计算系统。

## 2. 业务目标

构建一个可自动化、可扩展、可复现的估值系统，用于批量计算 A 股和 H 股上市公司的 DCF 内在价值，为投资决策提供估值参考。

## 3. 使用者角色

| 角色 | 使用需求 |
|---|---|
| 投研分析师 | 查看单只股票估值结果、核心假设和估值偏离度 |
| 量化研究员 | 将 DCF 估值偏离度作为选股因子或风控指标 |
| 投资经理 | 快速筛选被低估或高估的股票池 |
| 数据工程师 | 维护数据采集、清洗、入库和调度流程 |
| 项目评审者 | 评估系统架构、数据流程和协作规范是否完整 |

## 4. 功能需求

### 4.1 股票池管理

系统应支持：

- A 股股票池；
- H 股股票池；
- A+H 双重上市股票识别；
- 按市场、行业、交易所、上市状态筛选；
- 支持通过配置文件选择全市场或样本股票运行。

### 4.2 数据采集

系统应采集：

- 股票基础信息；
- 日度行情数据；
- 利润表；
- 资产负债表；
- 现金流量表；
- 总股本与流通股本；
- 无风险利率、市场风险溢价、行业参数等估值假设。

### 4.3 数据清洗

系统应完成：

- 股票代码格式统一；
- A 股人民币、H 股港币和财务报表币种统一；
- 会计期间对齐；
- 缺失值标记；
- 异常值检查；
- 重复数据去重；
- 财务指标口径统一。

### 4.4 DCF 估值计算

系统应支持：

- FCFF 模型；
- 可配置预测期；
- 可配置收入增长率、利润率、税率、资本开支率、营运资本假设；
- 可配置 WACC 和终端增长率；
- 企业价值、股权价值、每股内在价值计算；
- 当前价格与内在价值偏离度计算；
- 保存每只股票的估值假设和估值结果。

### 4.5 结果输出

系统应输出：

- 单只股票 DCF 明细；
- 全市场估值结果表；
- 估值偏离度排序；
- 异常股票清单；
- 数据质量报告；
- 可供下游策略使用的结构化结果表。

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 可扩展性 | 支持后续接入更多市场、数据源和估值模型 |
| 可配置性 | 股票范围、数据源、估值假设、运行频率均可配置 |
| 可复现性 | 每次估值结果需要保存运行日期、数据版本和参数版本 |
| 可维护性 | 模块边界清晰，文档完整，便于团队协作 |
| 稳定性 | 对数据缺失、接口失败和异常值有处理机制 |
| 审计性 | 估值结果可追溯到原始数据和假设参数 |

## 6. 业务边界

本设计方案只负责 DCF 估值结果的生成，不直接负责投资组合构建和交易执行。

系统输出的内在价值仅作为投资参考，不构成直接交易建议。
