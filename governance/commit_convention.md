# Commit 提交规范

## 1. 提交格式

```text
<type>: <short description>
```

## 2. 类型说明

| type | 含义 |
|---|---|
| docs | 文档修改 |
| config | 配置文件修改 |
| design | 架构或流程设计修改 |
| fix | 修正错误 |
| refactor | 重构文档结构 |
| chore | 其他维护工作 |

## 3. 示例

```text
docs: add DCF methodology document

design: update system architecture modules

config: add valuation assumption template

fix: correct WACC formula description
```

## 4. 提交要求

- 一次提交只解决一个主题；
- 提交说明应清楚表达修改内容；
- 不提交临时文件、缓存文件和敏感信息。
