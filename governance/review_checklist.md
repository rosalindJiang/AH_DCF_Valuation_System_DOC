# Review Checklist

## 1. 架构设计检查

- [ ] 是否说明系统分层架构；
- [ ] 是否明确每个模块职责；
- [ ] 是否说明数据源适配机制；
- [ ] 是否考虑批量运行和异常处理；
- [ ] 是否具有可扩展性。

## 2. 数据流程检查

- [ ] 是否覆盖股票池生成；
- [ ] 是否覆盖行情、财务、宏观参数；
- [ ] 是否说明数据清洗规则；
- [ ] 是否说明币种转换；
- [ ] 是否说明财务期间对齐；
- [ ] 是否说明估值结果入库。

## 3. DCF 方法检查

- [ ] 是否说明 FCFF 公式；
- [ ] 是否说明 WACC 计算；
- [ ] 是否说明终端价值计算；
- [ ] 是否说明股权价值和每股价值计算；
- [ ] 是否说明模型限制。

## 4. 协作规范检查

- [ ] 是否有分支规范；
- [ ] 是否有 commit 规范；
- [ ] 是否有 Issue 模板；
- [ ] 是否有 Pull Request 模板；
- [ ] 是否有评审清单。

## 5. 提交前最终检查

- [ ] 所有文件名清晰；
- [ ] README 可独立解释项目；
- [ ] 无真实账号、密钥、手机号、身份证等敏感信息；
- [ ] 明确说明不包含具体代码实现；
- [ ] 文件夹可直接上传 GitHub 或 Gitee。
